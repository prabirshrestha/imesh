# imesh

A cluster of equal machines over iroh, with one replicated SQLite database and no control plane.

```bash
npm install -g imesh
imesh --help
```

The package contains a prebuilt binary for your platform. Supported platforms:
macOS (arm64, x64), Linux (arm64, x64, static musl), Windows (arm64, x64).

Source: https://github.com/prabirshrestha/imesh
